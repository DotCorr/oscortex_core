oscortex_core M15 -- a program can read a file.
This file is under one cluster long and is read a line at a time
through core/user/libc/rfile.c, which buffers 512 bytes per read()
syscall and hands them out a line at a time.
It is NOT called FILE and rfopen is not called fopen, because it
cannot write, has no stdin, no stdout and no stderr, and does not
flush anything. A name that promised those would be a lie the
compiler could not catch.
